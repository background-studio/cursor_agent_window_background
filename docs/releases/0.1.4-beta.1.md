# Cursor Agent Background Studio 0.1.4-beta.1

本版为预发布版，建议与 **Background Studio 0.3.6-beta.2** 配套使用。

## 修复

- 兼容从 IDE 打开的新版独立 Agent 窗口，不再要求页面必须包含 `bc-window` 类。
- 关闭 Agent 窗口后重新打开，插件会自动发现并应用背景，无需再次点击“应用”。
- 修复原生最小化、最大化和关闭按钮区域异常拉高的问题；保持菜单栏原有布局并兼容缩放。
- 激活期间仅在 Agent 窗口隐藏 `background-cover` 的背景层，IDE 背景不受影响。
- 背景层丢失时重新安装；单个调试页面断连或正在导航时不阻断其他页面处理。

## 新增

- 通过 `perWindowMedia` 能力协商支持宿主按窗口独立分发媒体；窗口之间保留独立配置与轮播计时，新窗口不覆盖已有窗口的选择。
- 关闭窗口后释放其配置，暂停或恢复默认外观后停止自动注入。
- 媒体能力声明修正为既有内联实现实际支持的单文件 16 MiB 上限。

旧宿主仍使用同步单媒体协议；独立分发需要两端同时更新。不读取本机媒体路径，不修改 Cursor 安装文件或聊天内容。

## 验证范围

- 自动化：插件 22 项测试通过，包含实际生成的 JavaScript payload 和模拟 CDP 生命周期测试。
- 真实窗口：观察到连续 16 次随机换图，图片均成功加载；IDE 背景保持不变，原生按钮高度正常。
- 真实关闭重开：仅关闭 Agent 窗口，再通过 IDE 的 File → New Agents Window 重开，约 6.5 秒后自动应用背景（包含窗口加载），未手动应用、未重启 Cursor 主进程。
- **多个真实 Agent 窗口同时运行的场景尚未实测**，相关行为目前由自动化测试覆盖。
